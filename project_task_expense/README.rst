This module allows to create expenses related to project tasks.

Configuration
=============

To configure this module, you need to:

-  Go to a project's form view and activate the "Allow Tasks Expenses"
   option. It is only permitted to create expenses in tasks related to
   projects with this option activated

Usage
=====

To use this module, you need to:

1. Active the option Allow Tasks Expenses in those projects whose tasks
   can have expenses.
2. Go to a project task.
3. Click on the Expenses smartbutton to check, edit, create and delete
   expenses related to this task.
4. Review that the confirmed expenses appear in the analytic account of
   the project.
