This module allows to create subtasks that are, by default, displayed
inside their proyect.

Without this module, the subtasks can only be accesed, by default,
inside their parent task.

Usage
=====

To use this module, you need to:

1. Go to Project / Project. Select a project and then select a task.
2. Go to the Sub-tasks tab. Create a new sub-task.
3. Click on the "Sub-tasks" smartbutton. Create another sub-task.
4. Go back to the project tasks view. The subtasks you created should be
   visible (they are not without this module).
